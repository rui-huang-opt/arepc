# Active Reputation-based Consensus (A-RepC)

## Installation
Install via pip:

```bash
pip install git+https://github.com/rui-huang-opt/arepc.git
```

Or, for development:

```bash
git clone https://github.com/rui-huang-opt/arepc.git
cd arepc
pip install -e .
```
## Paper

Our paper is available on arXiv:

[**Byzantine-Resilient Consensus via Active Reputation Learning**](https://arxiv.org/abs/2605.11357)
