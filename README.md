# Adaptive Reputation-based Consensus (A-RepC)

A Python package implementing A-RepC, an adaptive reputation-based algorithm for Byzantine-resilient vector consensus without requiring prespecified fault bounds.

## Installation

Install directly from GitHub:

```bash
pip install git+https://github.com/rui-huang-opt/arepc.git
```

Or, for development:

```bash
git clone https://github.com/rui-huang-opt/arepc.git
cd arepc
pip install -e .
```

## Paper

This repository contains the implementation of our paper:

**Reputation-Based Byzantine-Resilient Vector Consensus without Prespecified Fault Bounds**

Available on arXiv: [arXiv:2605.11357 (v2)](https://arxiv.org/abs/2605.11357v2).
